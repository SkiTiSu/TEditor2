# Web 迁移验证记录

验证日期：2026-10-03。环境：macOS、Node.js 24.15.0、本机 Chrome 无头浏览器。

## 已通过

- `npm run build`：TypeScript 和生产构建通过，生成静态站点、离线缓存脚本和依赖许可证。
- `npm test`：382 项通过。其中 40 项文档测试、342 项数据与公式测试；公式包含 269 个旧版官方回归算例。
- Playwright：33 项完整回归通过，包含批量排版实时预览和旧离线缓存升级。
- 界面操作：四类图层、属性、顺序、复制删除、撤销重做、快捷键、移动缩放、条件组、数据行编辑及排序、分页、保存重开。
- 渲染像素：透明度蒙版、图层顺序、独立圆角、文字对齐锚点、内外居中描边、阴影、换行省略、重复排版和过期渲染竞争。
- 本地资源：旧 Windows 路径、大小写与同名歧义、内嵌 Base64、TIFF、缓存替换、IndexedDB 草稿和素材恢复。
- 输出：PNG 尺寸与透明度、ZIP 分包、重名避让、取消、失败中止，以及真实浏览器私有文件系统的写入。
- 生产离线：完成首次缓存后断网刷新，恢复模板、继续编辑并导出 PNG。

## 自造数据与批量验证

样例文件为 `public/examples/legacy-all-features.ted` 和配套 `legacy-data.csv`。默认演示中的头像、姓名、标题和表格也由代码生成。

实际渲染并编码了 500 张 1920×1080 PNG，全部文件头和尺寸有效，输出共 63,873,235 字节。最近一次完整回归测得约 4.06 秒，复用了 8 个画布，写入并发始终为 1。详情见同目录的 `500-image-benchmark.json`。

500 张基准使用验证后丢弃内容的模拟写入器，不包含物理磁盘耗时；真实 FileSystemWritableFileStream 另用小批量验证。JavaScript 堆采样不包括浏览器原生画布、图片解码和 PNG 编码器的全部内存，不能作为总内存峰值。

## 兼容边界

没有使用真实用户模板或运行旧 WPF 程序进行逐像素对比。浏览器与 WPF 的字体度量、字形边缘可能不同；极端统计精度及少见的 .NET 日期格式存在兼容边界，见 `src/vendor/toolgood/README.md`。完全位于画布外的文字向画布内投射阴影这一特殊边界也可能与旧版不同。

本次范围为旧版 GUI 功能，按用户确认不提供命令行。新模板为版本 1，支持导入旧版本 0，不保证旧程序可读取新文件。

